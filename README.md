# Nairobi Elite Auto Care

A professional, responsive business website created as **Portfolio Project 1**.

## Project overview

Nairobi Elite Auto Care is a fictional Kenyan automotive business used to demonstrate front-end web development skills.

### Features

- Responsive mobile-first layout
- Home, Services, About, Why Us and Contact sections
- Functional front-end contact form demo
- WhatsApp call-to-action button
- Smooth scrolling
- Scroll reveal animations
- SEO meta description and keywords
- Open Graph metadata
- Accessible labels and navigation
- Reduced-motion support
- No external libraries or frameworks
- Lightweight and fast-loading

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript

## Run locally

No installation is required.

1. Download or clone this repository.
2. Open `index.html` in a browser.

For a better local development experience, use VS Code with the Live Server extension.

## Portfolio notes

This is a fictional portfolio project. Phone numbers, email addresses and testimonials are sample content.

## Deployment

The project can be deployed directly to GitHub Pages, Netlify, Vercel or another static hosting provider.
